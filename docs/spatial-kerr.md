# 円形ファイバ内の反射と空間 Kerr 効果

この文書は、光がコアとクラッドの境界付近で折り返しながら進む様子と、
Kerr 効果による空間的な変化を、計算した光の場から描くための条件・方法・結果を説明する。
設計相談は [Issue #23](https://github.com/Motoki0705/optical-comm-lab/issues/23)、
円形断面の物理モデルと数値確認は
[Issue #24](https://github.com/Motoki0705/optical-comm-lab/issues/24) が担当する。
4条件の場・流線と主2条件の等強度面は
[計算マニフェスト](../artifacts/spatial_kerr/manifest.json)に登録して保存した。
横格子の確認は0.8 mmまでに限られ、全3 mmの精密な空間収束を保証しない。
動画の制作は [Issue #25](https://github.com/Motoki0705/optical-comm-lab/issues/25)、
動画を使う説明資料は [Issue #27](https://github.com/Motoki0705/optical-comm-lab/issues/27)
で別に進めており、ここでは完成した映像として案内しない。

## 何を計算して見せるか

Kerr 効果では、光の強い場所ほど屈折率が変わる。正の係数を持つこのモデルでは、
明るい領域の屈折率が上がり、それが光の位相と横方向の広がり方に作用する。
同じ入射光について Kerr を切った場合と入れた場合を計算し、境界付近での
折り返し、光の幅、位相、横方向の流れにどの程度の差が出るかを調べる。
差の大きさや漏れの有無は計算結果で判断する。

既存の [80 km のパルス映像](kerr-physics.md) は、距離 `z` とパルス内の
相対時刻 `t` による包絡線 `A(z,t)` を解いている。横方向の位置、円形の境界、
反射位置を持たないため、[そこに描いた電場の曲線](kerr-rendering.md) は
空間を進む光線を表さない。今回のモデルでは、断面の二つの座標 `x,y` を持つ
複素場 `ψ(x,y,z)` を解き、境界と光の流れを計算に含める。

| 計算 | 扱う問い |
| --- | --- |
| 1600 km の通信・学習研究 | 雑音と伝送ひずみを受けた通信信号を、リザバーでどこまで補償できるか |
| 80 km の孤立パルス | パルスの時間波形、位相、チャープ、スペクトルがどう変わるか |
| 今回の円形断面モデル | コア内の空間場と横方向の流れが、境界と Kerr によってどう変わるか |

今回の結果から新しい BER や学習性能を主張しない。平面スラブの予備計算も、
円形ファイバの検証結果に数えない。

## 作業仮定と保存した条件

反射の様子を読み取りやすくするため、教育用の多モード条件と、強い仮の
Kerr 係数を使って計算した。教育上の見やすさと実通信条件のどちらを
優先するかについて、ユーザーの選択はまだ得られていない。以下は作業仮定であり、
実際のシリカ通信ファイバの再現条件や、ユーザーが承認した教育条件とは扱わない。

| 量 | 保存した条件 |
| --- | --- |
| 真空波長 `λ` | 1.55 µm |
| コア半径 `a` | 25 µm、直径 50 µm の円形 |
| 線形屈折率 | コア 1.450、クラッド 1.445、差 0.005 |
| 伝搬距離 | 3 mm |
| 入射場 | `ψ(x,y,0)=exp[-(x²+y²)/w²] exp[i β₀ tan(θ) x]` |
| 入射幅と傾き | `w=12 µm` は振幅の 1/e 半径、`θ=3°` は近軸モデルでの流れの傾き |
| 強度の基準 | `I=|ψ|²`、入射ピークを 1 とする無次元量 |
| Kerr 比較 `κ` | 0、1.6×10⁻¹¹、1×10⁻⁴、3×10⁻⁴ の4条件をすべて保存 |

この条件の `V=(2πa/λ) sqrt(n_core²-n_clad²)` は約 12.2 であり、
単一モード通信ファイバの条件ではない。実製品の寸法との比較には、
コア径 8.2 µm、クラッド径 125 µm を示す
[Corning SMF-28 ULL のデータシート](https://www.corning.com/media/worldwide/coc/documents/Fiber/SMF-28%20ULL.pdf)
を使う。今回のコア径や屈折率を、この製品の仕様として示さない。

`κ` は正規化した強度あたりの無次元屈折率変化で、
`Δn_NL=κ I` と定義する。材料の `n₂` [m²/W] や入力電力 [W] ではない。
実強度の尺度 `I_ref` [W/m²] を別途決めれば `κ=n₂ I_ref` と対応づけられるが、
このモデルではその尺度を定めない。強度と非線形係数の積の規約が必要な理由は
[Meep の単位と非線形性の説明](https://meep.readthedocs.io/en/stable/Units_and_Nonlinearity/)
にも示されている。

強条件 `κ=3×10⁻⁴` の入射ピークでの変化は、線形屈折率差の 6% にあたる。
これは変化を比較するための仮の強条件であり、50 mW のシリカに相当すると
説明しない。1.6×10⁻¹¹ は弱い変化を対照に残すための参考値であり、この
50 µm コアの実電力を較正した値でもない。材料損傷、加熱、飽和は計算に含めない。

## 解く方程式とその範囲

`k₀=2π/λ`、`β₀=n_core k₀` とし、前向きの搬送波
`exp(iβ₀z)` を除いたスカラー包絡線を次の近軸方程式で伝搬させる。
式の座標を SI 単位にすれば `k₀,β₀,α` の単位は m⁻¹ になる。

\[
i\frac{\partial\psi}{\partial z}
=-\frac{\nabla_\perp^2\psi}{2\beta_0}
-\left[\frac{k_0^2\bigl(n_{\rm lin}^2(x,y)-n_{\rm core}^2\bigr)}{2\beta_0}
+k_0\kappa|\psi|^2\right]\psi
-i\alpha(x,y)\psi .
\]

`n_lin` は `sqrt(x²+y²)<a` でコア値、その外でクラッド値をとる。
第1項は回折、第2項の線形部分は円形の屈折率段差、`κ` の項は強度に応じた
位相変化を表す。非線形部分は、`n_lin/n_core≈1` と小さい屈折率変化を用いる
一次近似であり、完全な非線形 Helmholtz 方程式を解いたとは呼ばない。
`κ` はコアとクラッドに共通とし、
コアだけに Kerr を限定するマスクは入れない。

`α≥0` は計算窓の遠い外縁に置く人工吸収の振幅減衰率で、観察するコア近傍では
0 とする。外へ進んだ場が FFT の周期境界を回って戻るのを抑えるために使い、
シリカの伝送損失として解釈しない。保存計算では半径100 µmから立ち上げ、
125 µmで最大0.1 µm⁻¹となる4乗の分布を使った。クラッドは無限に続く近似であり、
半径62.5 µmのガラスと空気の境界は解いていない。
吸収に伴う積分強度の減少率は `-2∫αI dxdy` であり、吸収した量を記録する。
`∫I dxdy` は正規化場の積分で、電力を W に変換する尺度は持たない。

計算は横2次元と伝搬方向 `z` を扱い、時間に依存しない連続光（CW）を仮定する。
円形断面、回折、場の干渉、クラッド側の場と横の流れを含める。偏波、時間パルス、
`z` の逆向きに戻る光、3次元の完全な Maxwell 方程式は扱わない。ここで描く
「反射」は、前向きに進む場の横方向の流れがコア境界付近で折り返すことを指す。
近軸 BPM の前向き伝搬という適用範囲は
[薮、レーザー研究 36, 628–634 (2008)](https://www.jstage.jst.go.jp/article/lsj/36/10/36_628/_article/-char/en)
に基づいて区別する。

横方向の回折を Fourier 空間で、屈折率・Kerr・吸収を実空間で扱う対称分割を使う。
回折演算子は `exp[-i(kx²+ky²)dz/(2β₀)]`。局所区間の Kerr 位相には、
同区間で吸収によって減る強度を積分して用いる。吸収と非線形位相をそれぞれ
入射強度のまま加算する実装ではない。

| 数値条件 | 保存した値 |
| --- | --- |
| 横格子 | `dx=dy=0.25 µm`、1000×1000点、セル中心配置 |
| 計算窓 | `x,y` はそれぞれ −125〜+125 µm の周期窓、外縁に人工吸収 |
| 距離刻み | `dz=0.0625 µm`、48000ステップ |
| 場・観測量の計算精度 | complex128 / float64、CuPy 14.2.0、NVIDIA GeForce RTX 5060 Ti |
| 全場の診断間隔 | 5 µm。コア内重心・RMS幅・積分強度などを計算 |
| 描画用の断面と流れの標本 | 横0.5 µm、距離2.5 µm、固定ROI約±50 µm |

条件は [configs/spatial_kerr.json](../configs/spatial_kerr.json)、
実行環境と全入力のハッシュは
[manifest.json](../artifacts/spatial_kerr/manifest.json)に保存する。
描画用の間引きと、物理計算の格子を区別する。

## 計算から作る線と映像

強度に加えて、近軸方程式の連続の式に対応する横方向の流れ

\[
\mathbf J_\perp=\frac{\operatorname{Im}(\psi^*\nabla_\perp\psi)}{\beta_0},
\qquad
\frac{d\mathbf r_\perp}{dz}=\frac{\mathbf J_\perp}{I}
\]

を計算する。この流れに沿う線を、光が進む方向を読むために重ねる。
線は個々の光子の軌道ではない。場の節や強度の低い場所では `J/I` が不安定に
なるため、入力ピークを1とする強度のしきい値 `I=10⁻⁴` を使い、線を止めた位置や
有効範囲を保存した。入力の等パワー分位点から5×5の25本を出し、線を選別しない。
境界の折り返しを手で置いたり、見栄えのために流線を曲げたりしない。

保存した流線は線形補間と0.5 µmの積分刻みを使う。刻みを0.25 µmへ半減した差は
最大0.0191 µm（線形条件）と0.0355 µm（強条件）だった。一方、線形補間から
cubic補間へ変えた差は最大2.03 µmと0.777 µmであり、刻みの差より大きい。
したがって流線は近似的なエネルギー流の表示として使い、細かな線の位置や
反射点を定量的に資格付けたとは扱わない。位置・幅の数値は全場の強度から得る。
線形・弱参照・強条件は25本すべて終端まで進んだ。中間条件は1本が1.685 mmで
しきい値未満となり、24本が完走した。打ち切った線も有効マスクとともに保存した。

複数の映像では、同じ入射条件と固定した表示尺度を使って、強度と幅、
線形解に対する位相差 `arg(ψ_Kerr ψ_linear*)`、横方向の流れをそれぞれ読めるようにする。
弱い参照条件も残し、変化が見えない場合はその結果を示す。弱い領域の位相差には
両方の場の強度によるマスクを使い、各条件や各距離を独立に最大値へ正規化しない。
漏れを示す場合は、コア外の積分強度と吸収層へ到達した量を分けて読む。

Kerr の位相は局所強度に応じて伝搬中に蓄積する。境界で反射するたびにだけ
位相を足す説明は使わない。正の `κ` があっても、複雑な導波場のコア外成分や
放射が必ずゼロになるとは仮定しない。非線形導波場でのモード間結合と自己収束は
[Finlayson ほか、Applied Physics Letters 50, 1562–1564 (1987)](https://doi.org/10.1063/1.97780)
でも扱われており、符号だけから映像の結論を決められない。

Blender は保存した場と流線を撮影する。ガラスの材質、照明、カメラは描画であり、
Blender のレンダラーが Kerr 伝搬を解くわけではない。計算座標、断面や長さの表示倍率、
不可視の赤外光に付けた色、補間、切り欠き、画面外の範囲を記録する。
`z` の走査やカメラの移動は観察の時間配分で、実際の光の伝搬時間ではない。
CW の定常分布を、計算していない短パルスの移動として説明しない。

## 保存した結果

[metrics.json](../artifacts/spatial_kerr/metrics.json)の `cases` に4条件すべての
結果を保存した。次の幅はコア内重心からのRMS半径、コア内割合は入力の積分強度に
対する値。主結論には、計算窓や吸収層に影響される全領域のRMS幅を使わない。

| 条件 | `κ` | 3 mmのコア内強度の相対L2差 | 3 mmのコア内RMS半径 [µm] | 3 mmのコア内割合 [%] |
| --- | ---: | ---: | ---: | ---: |
| 線形 | 0 | 0 | 16.314760 | 92.5211 |
| 弱参照 | 1.6×10⁻¹¹ | 1.22946×10⁻⁸ | 16.314760 | 92.5211 |
| 中間 | 1×10⁻⁴ | 0.0807237 | 16.303926 | 93.2999 |
| 強条件 | 3×10⁻⁴ | 0.266150 | 16.202795 | 94.6715 |

相対L2差は `||I_a-I_b||₂ / ||I_b||₂` をコア内で計算する。
条件比較は `a=linear, b=比較する条件` であり、分母を線形条件のノルムに
統一した値ではない。これは分布の違いの指標で、失われた光の割合ではない。
強条件では伝搬中のコア内横重心差の最大値が2.024216 µm、終端の位相差の
重み付きRMSが1.276608 radだった。位相差は `arg(ψ_b ψ_a*)` の −π〜+π の値で、
両場の強度が10⁻⁴以上のコア内を使い、重みを `min(I_a,I_b)` とする。

強い仮条件では位相・分布・重心に差が出たが、終端のコア内幅の変化は小さく、
光が単調に細くなるという結論にはしない。弱参照の分布は線形とほぼ同じであり、
その微小な差の絶対精度は、以下の格子確認や近軸モデルの限界から保証できない。
コア内に残る割合の差も、この教育条件での観測であり通信補償性能の改善を示さない。

## 通常の数値確認と限界

`metrics.json` の `qualification` に独立な解析制御と条件変更の差を保存した。
解析制御の誤差は全横計算窓で比較し、条件変更の相対L2差はコア内で比較する。
条件変更でも分母は比較先 `b` のノルムを用いる。位相・振幅を結果に合わせて
フィットする補正は行っていない。

| 解析制御 | 距離 | 比較量と実測差 |
| --- | --- | --- |
| 自由空間の2次元Gaussian | 200 µm | 複素場の相対L2誤差1.13×10⁻¹² |
| 一様Kerr、吸収なし | 1000 µm | 複素場の相対L2誤差2.26×10⁻¹² |
| 一様Kerr、一定 `α=2×10⁻⁴ µm⁻¹` | 1000 µm | 複素場の相対L2誤差1.77×10⁻¹² |
| 円形ステップ屈折率のLP01 | 800 µm | 強度の相対L2誤差6.12×10⁻⁴、複素場4.65×10⁻⁴ |

吸収なしの一様Kerrは `ψ(z)=ψ(0) exp[i k₀κI z]`、吸収ありは指数減衰と
同区間の積分強度による位相を解析解にする。LP01はBessel関数の境界条件から
得た場を使い、近軸方程式に対応する `exp[i(β_mode²-β₀²)z/(2β₀)]` と比較する。
LP01の点標本による境界誤差は残っており、解析制御すべてが機械精度で一致したとは言えない。
主4条件の `remaining_power + absorbed_power - 1` の最大絶対値は8.37×10⁻¹²以下だった。
この収支の一致だけでは、場の空間形状の精度を保証しない。

| 条件変更 | 比較距離 | コア内終端強度の相対L2差 |
| --- | --- | ---: |
| 強条件の `dz=0.0625→0.03125 µm` | 3 mm | 2.449×10⁻⁶ |
| 強条件の `dx=dy=0.25→0.125 µm`、同じ `dz=0.03125 µm` | 0.8 mm | 9.790×10⁻⁴ |
| コアと入射場を横格子の半セルずらして座標を整列 | 0.8 mm | 0.0123732（1.2373%） |
| 入射方向を45°回転し、共通座標へ3次補間で整列 | 0.8 mm | 0.00112689（0.1127%） |
| 線形条件の窓半幅125→150 µm、吸収開始100→125 µm | 3 mm | 0.000154899（0.01549%） |
| 強条件の同じ窓変更 | 3 mm | 0.0000812956（0.00813%） |

距離刻み0.125、0.0625、0.03125 µmの複素場の差の比は4.121で、
この刻み範囲の2次収束と整合する。一方、横格子・半セル・方向の比較は
最初の反射を含む0.8 mmまでであり、全3 mmの精密な空間収束や完全な
電磁場の精度を確立したとは扱わない。表の差は試した条件での観測で、
誤差の絶対的な上限ではない。特に半セル配置の差は残っており、
距離刻みの小さな差だけを全体精度として案内しない。

横2次元の自己収束は、横1次元のスラブ試作とは異なる。バルク媒質での崩壊しきい値を
論じる [Fibich と Gaeta、Optics Letters 25, 335–337 (2000)](https://doi.org/10.1364/OL.25.000335)
は重要な参照だが、それだけで円形導波路の安定性や格子の十分性を保証しない。
鋭いピークが現れた場合は格子依存と適用範囲を調べ、滑らかな表示で隠さない。

## 保存形式と再生成

保存先は [artifacts/spatial_kerr/](../artifacts/spatial_kerr/)。数値指標は全計算窓の場から
求め、描画用の約±50 µmのROIや間引いた断面から再計算した値と混同しない。
横の保存座標は −49.875〜49.625 µm、中心断面は最近傍の対称2行から複素場を
線形補間して `y=0` に置く。保存間隔のNyquistを超える横波数の電力割合を、
9つの横断面の位置で元の全場から測り、最大2.66×10⁻⁸だった。
これは間引きの診断であり、空間収束や流線の位置精度を保証しない。

| ファイル | 主な内容 |
| --- | --- |
| `<case>_sections.npz`、4条件 | `x_um,y_um` は各200点、`z_um` は1201点、`central_psi` は(1201,200)、`cross_psi` は(9,200,200)、複素場はcomplex128 |
| 同じsections内の診断量 | `diagnostic_z_um` は601点。全場から得た積分強度、コア内重心、幅など、float64 |
| `<case>_flows.npz`、4条件 | `position_um` は(25,6001,3)、`valid` はbool。有効マスク、開始点と分位点、強度、横速度を保存 |
| `<case>_iso_0p1/0p3/0p6.npz`、線形と強条件 | 固定強度0.1、0.3、0.6の等強度面、計6件。頂点・法線はfloat32、三角形の索引はint32 |
| `metrics.json` | 4条件の結果、解析・格子確認、流線の打ち切りと比較、メッシュと保存標本の診断 |
| `manifest.json` | 条件・入力・ソース・保存ファイルのSHA-256、バイト数、実行環境、座標契約 |
| `verification.json` | 保存ファイル・ソースのハッシュ、断面軸と型、流線のマスク、メッシュ索引の監査結果 |

NPZは `allow_pickle=False` で読む。物理座標は `XYZ=(横x,横y,伝搬z)`、横断面配列は
`(snapshot,y,x)`。流線とメッシュを作る一時的な強度・横流れの体積標本は
`(z,y,x)` のfloat32で `.work/` に分離し、元の場のcomplex128計算と区別する。
保存したファイルは約109 MB、最大の1件は16.2 MB。GPU伝搬を含む生成・検証・抽出の
全工程は35.8分で、CPU実行時間や別の装置での速度は測定していない。

生成には登録済みの環境と `spatial` 任意依存が必要で、標準設定はCuPyのGPU計算を使う。
次は既存の成果物を変更しない再生成と、伝搬を行わない監査のコマンドである。

```bash
# 同じ条件で、新しい空の出力先・一時保存先へ生成する。
.venv/bin/python scripts/simulate_spatial_kerr.py --config configs/spatial_kerr.json --output .work/spatial-reproduction --scratch .work/spatial-reproduction-bulk

# 保存ファイルとソース、形状、有効マスクを読み取り専用で照合する。
.venv/bin/python scripts/simulate_spatial_kerr.py --verify-only --output artifacts/spatial_kerr
```

CPUでの再生成は `--backend numpy` を明示する。出力先とscratchは空である必要があり、
既存データを無言で再利用しない。`--skip-qualification` は探索用で、今回保存した
通常検証を含む計算と同じ資格付けにはならない。
登録済みの [verification.json](../artifacts/spatial_kerr/verification.json) と今回の監査で、
全4条件のハッシュ・軸・型・流線マスク・メッシュ索引を照合した。
追加タスクの独立validatorは指定・試行・完了とも0回で、元の通信研究の1回を流用しない。

## Claude Code Opus の助言の位置づけ

Claude Code 2.1.296 に `--model opus --effort high`、読み取り専用で相談した。
実行記録の `modelUsage` は `claude-opus-5-5`、`is_error` は `false` だった。
相談の範囲と助言の採否は [Issue #23](https://github.com/Motoki0705/optical-comm-lab/issues/23)
に残す。これは設計相談であり、独立 validator や数値精度の保証ではない。

主な採用点は、時間包絡線だけでは反射を示せないため空間場を解くこと、
場の流れから線を求めること、Kerr の有無を同条件で比較すること、強い条件を
実材料の値と区別することである。スラブの簡易案は探索に使い、今回の対象は
円形断面とする。厳密 Helmholtz という呼称、正の非線形性なら漏れが絶対に
起きないという断定、反射のたびにだけ Kerr 位相が加わる説明は採用しない。
