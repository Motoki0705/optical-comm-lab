## 物理計算と表現

80 kmの損失・二偏波Manakov伝搬を、既存のSSFM通信路で計算した説明用実験。ガウスパルスの瞬間ピーク電力はXY合計50 mW、強度の1/e半幅は20 ps。自己位相変調だけ、分散だけ、両方の三つの条件を分けた。増幅器・ASE・通信シンボル・学習・BER評価は含まない。本研究の1600 km評価とは別のデータであり、補償性能の根拠には用いない。

冒頭の横断面は、クラッド直径125 µmとコア直径8.2 µmの比を保持した。細部ではコアの表示を冒頭に対して約21倍に拡大する。ガラスの切り欠きと器具は説明用のモデルで、電場と透明な輪郭はその中に重ねた計算量の可視化。

**横方向**：パルスと一緒に進む時間の座標。生成する電場形状は-240〜240 psの共通範囲で、カメラがその内部を接写する。低い裾は画面の外に出ることがある。映像中のガラスの長さは説明用の縮尺。

**線の揺れ**：計算したX・Y偏波の電場から作る。見えるように振動の周期を12 psへ拡大した。実際の1550 nmの光に対して約2,321倍。この入力の偏光方向は一定。

**透明な輪郭**：電力の平方根に比例する振幅を、大きさに置き換えた模式表現。線と輪郭には、3本・全距離で共通の尺度を使う。16 dBの伝送損失も残している。

**色**：位相を見分けるための色分け。青緑は0、橙は正側、青は負側、折り返しの境界は紫。光の見える色を撮影したものとしては読まない。ごく弱い裾では色を隠す。

**映像の進行**：距離0〜80 kmに伴う変化を、ゆっくり見る。1 km刻みの81波形の間は描画する形状と色を補間し、各動画フレームをBlenderでレンダリングした。上映時間は実際の飛行時間を表す値ではない。

計算条件・数値確認・出典は [物理モデルの文書](../../../docs/kerr-physics.md)、原データは [計算マニフェスト](../../../artifacts/kerr-physics/manifest.json) と [導出量](../../../artifacts/kerr-physics/derived_metrics.json) を参照する。映像の設定と再描画コマンドは [manifest.json](manifest.json) と [描画手順](../../../docs/kerr-rendering.md) に保存した。解析極限との照合、エネルギー保存と損失の確認、距離刻み・時間刻み・計算窓を変えた比較、保存用データの確認を行い、記録した通常検証の基準を満たした。独立validator評価は今回実施していない。

## 解説の再生成

リポジトリ直下で、保存済みの計算データと3本の映像から再生成する。Python標準ライブラリだけで動作し、伝搬・学習・レンダリングは行わない。

```bash
.venv/bin/python scripts/build_kerr_explanation.py --physics-run artifacts/kerr-physics --renders reports/animations/kerr_physics
```

計算マニフェストに記録されたソース・設定・全artifact、映像マニフェストの入力・出力をSHA-256で照合する。未完成の計算、数値確認に失敗した計算、欠落・変更された動画や入力からは生成しない。`--output-dir .work/kerr-explanation-check` を追加すれば、公開済みのHTMLとREADMEを変更せずに確認できる。

計算と動画をやり直すときは、[描画手順](../../../docs/kerr-rendering.md)にある `.venv/bin/python` のコマンドを使い、保存済み成果物と分けた出力先で実行する。描画マニフェストの `python3` は、Pillowを含むプロジェクト環境を有効にしたPythonを想定している。GPU・Blender・FFmpegの差で画素やエンコード済みのバイト列が変わる可能性があり、SHA-256は今回保存した版を識別するための記録。

描画ではパルス内の時刻方向に4倍の密度で複素電場を線形補間する。元の物理標本点と、数値結果の導出量は保持する。詳細は映像マニフェストの `display_time_upsampling` を参照する。接写で画面の外に出る低い裾と、数値データ窓の切り取りによる省略は区別する。

[explanation_manifest.json](explanation_manifest.json) は入力と出力のハッシュ、生成CLIの版、環境、再生成コマンドと通常確認を記録する。自己参照を避けるため、そのマニフェスト自身のハッシュは内包しない。独立validator評価は今回のタスクでは指定0・試行0・完了0。

旧版の30秒の模式アニメーションは [当時のREADME](../kerr/README.md) とマニフェストを保持している。こちらは別の生成物で、今回の物理計算動画の入力ではない。
